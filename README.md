🎮 Number Guessing Game

📌 Project Description

	This is a fun and interactive Number Guessing Game developed using HTML, CSS, and JavaScript.
	The game generates a random number between 1 and 100, and the player has to guess the correct number within limited attempts. The application provides hints like Too High or Too Low to help the player.
	It also includes attractive full-screen Win and Lose popups for a better gaming experience.

🚀 Features

	🎯 Random number generation
	📉 Too High / 📈 Too Low hints
	⏳ Attempt counter
	🏆 Full-screen Win popup
	💀 Full-screen Lose popup
	🔄 Restart game option
	🎨 Modern centered UI design
	📱 Responsive layout

🛠️ Technologies Used

	HTML
	CSS
	JavaScript

▶️ How to Run

	Download or clone the repository
	Open the project folder in VS Code
	Install the Live Server extension
	Right-click index.html
	Click Open with Live Server

🎮 How to Play

	Enter a number between 1 and 100
	Click Submit
	The game will tell whether your guess is:
	📉 Too High
	📈 Too Low
	Guess the correct number before attempts finish
	Win or Lose screen will appear

📸 Output

	🎉 Full-screen “YOU WON” popup on correct guess
	💀 Full-screen “YOU LOSE” popup after maximum attempts
